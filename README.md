# JavaScript Temelleri: If-Else Ödevleri

## Proje Hakkında

Bu projede JavaScript'in temel koşul yapıları üzerinde çalışarak algoritma kurma ve problem çözme becerilerimi geliştirmeyi amaçladım. Toplam 25 sorudan oluşan ödev kapsamında günlük hayattan örnekler içeren farklı problemleri JavaScript kullanarak çözmeye çalıştım.

## Kullanılan Teknolojiler

- JavaScript
- HTML
- Visual Studio Code

## Çalışılan Konular

- `if`, `else if` ve `else` koşul yapıları
- Karşılaştırma operatörleri
- Mantıksal operatörler (`&&`, `||`, `!`)
- Mod alma operatörü (`%`)
- Değişkenler ve veri türleri
- String uzunluğu kontrolü (`.length`)
- Matematiksel işlemler ve hesaplamalar
- İç içe koşul yapıları
- Koşulların doğru sıralanması
- Günlük hayattaki problemlerin algoritmaya dönüştürülmesi

## Tamamlanan Ödevler

İlk 18 soruyu tamamlayarak temel koşul yapılarından daha kapsamlı problemlere kadar farklı senaryolar üzerinde çalıştım.

Çözdüğüm problemler arasında şunlar yer alıyor:

- Pil seviyesi kontrolü
- Tam bölünebilme kontrolü
- Asansör kapasitesi hesaplama
- Kullanıcı adı uzunluğu kontrolü
- Gece modu otomasyonu
- Suyun hâllerini belirleme
- Hız sınırı aşımı ve ceza hesaplama
- Kahve makinesi koşullarını kontrol etme
- İkinci dereceden denklemin kök durumunu belirleme
- Depolama alanı kontrolü
- Koordinat düzleminde bölge bulma
- Kademeli elektrik faturası hesaplama
- Otopark ücret tarifesi
- Kredi başvurusu değerlendirme
- Uçak bagaj ek ücreti hesaplama
- Akıllı ev kombi kontrolü
- İndirim kuponu doğrulama

## Öğrenme Sürecim

İlk 18 soruyu tamamlayarak öğrendiğim koşul yapılarını farklı senaryolarda uygulama fırsatı buldum. Özellikle birden fazla koşulu birlikte değerlendirme, koşulları doğru sıraya koyma ve matematiksel işlemleri algoritmaya dönüştürme konularında pratik yaptım.

19–25 arasındaki sorular ise mevcut bilgi seviyeme göre daha zorlayıcı geldi. Artık yıl hesaplama, Taş-Kâğıt-Makas oyunu, ortanca sayıyı bulma, ATM banknot dağıtımı, dijital saat, oyun hasarı hesaplama ve tarih doğrulama gibi problemleri henüz tamamlayamadım.

Bu soruları eksik kalan konularımı görmek ve ilerleyen süreçte öğrendiklerimi pekiştirerek yeniden çözmek için bir fırsat olarak değerlendiriyorum.

## Projenin Amacı

JavaScript'in temel koşul yapılarını daha iyi anlamak, algoritmik düşünme becerimi geliştirmek ve zamanla daha karmaşık problemleri bağımsız olarak çözebilecek seviyeye ulaşmak.

Bu proje, yazılım öğrenme sürecimdeki gelişimimi ve üzerinde çalıştığım konuları gösteren bir uygulama çalışmasıdır.
